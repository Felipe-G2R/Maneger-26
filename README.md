# Maneger 26

PWA de gestão de metas para 2026, com diário por voz e mural de evolução.

**Stack:** React, React Router, Zustand, Recharts, Supabase e Vite, instalável como PWA.

## Rodar

```bash
npm install
cp .env.example .env   # preencha as chaves do seu projeto Supabase
npm run dev
```

O esquema do banco e os dados de exemplo estão em `supabase-schema` e `seed-goals.sql`. Passo a passo completo em [`QUICKSTART.md`](QUICKSTART.md).
